# Life Manager SaaS

Комплексний веб-додаток для керування особистим життям: фінансами, завданнями, тренуваннями та показниками здоров'я. Проєкт розроблено в рамках навчального курсу (MVP версія).

## 🚀 Технологічний стек

**Frontend:**
- [Next.js](https://nextjs.org/) (App Router)
- React
- Tailwind CSS
- next-themes (підтримка темної теми)
- Axios (HTTP клієнт)

**Backend (Окремий сервіс):**
- [NestJS](https://nestjs.com/)
- MongoDB / Mongoose
- JWT (Авторизація та аутентифікація)
- Cloudinary (Зберігання медіафайлів/чеків)

## 🎯 Основний функціонал

1. **Панель управління (Dashboard)**
    - Віджет актуальних курсів валют (НБУ + Binance API).
    - Віджет погоди (OpenMeteo API) з можливістю вибору міста.
    - Стрічка останньої активності користувача.

2. **Фінанси**
    - Облік доходів та витрат.
    - Завантаження фотографій чеків.
    - Пагінація, фільтрація за типом та пошук за категорією.
    - Сортування транзакцій.

3. **Завдання (Канбан-дошка)**
    - Створення завдань, додавання нотаток та призначення відповідальних.
    - Зміна статусів: `New` -> `In Progress` -> `Done`.

4. **Здоров'я та Тренування**
    - Розрахунок денної норми калорій за формулою Міффліна-Сан Жеора.
    - Трекінг випитої води, ваги та пройдених кроків.
    - Журнал тренувань з графіком прогресу ваги у конкретних вправах.

5. **CRM / Admin Panel**
    - Керування користувачами (блокування, зміна ролей).
    - Загальна статистика платформи.
    - Генерація токенів активації.
