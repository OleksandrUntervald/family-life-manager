# Family Life Manager 🏠

Повноцінний Full-Stack веб-додаток для керування повсякденними сімейними та особистими справами. Система об'єднує в собі облік фінансів, планування завдань, моніторинг показників здоров'я, тренування та контроль за обслуговуванням техніки.

## 🚀 Ключові можливості (Features)

- 🔐 **Аутентифікація та Безпека:** Реєстрація, JWT-авторизація, захищений профіль користувача з можливістю зміни імені та безпечного оновлення пароля (хешування через `bcrypt`).
- 💰 **Фінанси:** Повний CRUD для транзакцій — трекінг доходів та витрат, контроль сімейного бюджету.
- 📋 **Завдання та Цілі:** Планування справ на день, відмітка про виконання, редагування та видалення.
- 🏋️ **Тренування:** Фіксація фізичної активності, запис підходів, ваги та вправ.
- 🍏 **Здоров'я:** Моніторинг щоденної ваги, спожитих калорій та кількості кроків.
- 🛠️ **Дім та Техніка:** Журнал обслуговування автомобілів, заміни фільтрів та ремонту побутової техніки.
- 📈 **Аналітика:** Наочна візуалізація фінансових витрат та показників здоров'я за допомогою інтерактивних графіків (`Recharts`).
- 🛡️ **Фільтрація контенту:** Вбудований глобальний `ProfanityInterceptor` на бекенді (RegEx) для автоматичного цензурування нецензурної лексики у всіх текстових полях.

## 🛠 Технологічний стек (Tech Stack)

**Frontend:**
- [Next.js 15+](https://nextjs.org/)
- [React 19](https://react.dev/)
- [Tailwind CSS v4](https://tailwindcss.com/)
- [Recharts](https://recharts.org/) (для графіків)
- Axios & js-cookie

**Backend:**
- [NestJS v11](https://nestjs.com/)
- TypeScript
- MongoDB & [Mongoose](https://mongoosejs.com/) (база даних розгорнута в MongoDB Atlas)
- JWT (Passport.js), bcrypt, class-validator

**Інфраструктура:**
- Docker & Docker Compose
