# 🚀 Family Life Manager SaaS

Повнофункціональна Full-Stack SaaS-платформа для комплексного особистого та сімейного менеджменту: контроль фінансів з підтримкою чеків і 11 світових валют, Kanban-дошка спільних та особистих завдань, розумний фітнес-асистент (динамічний розрахунок BMR за формулою Міффліна-Сан Жеора), щоденник силових тренувань, облік обслуговування автомобілів і побутової техніки, візуальна аналітика та CRM Адмін-панель (God Mode).

---

## 🛠️ Технологічний стек

### Backend (`/backend`)
* **Фреймворк:** NestJS (Node.js + TypeScript)
* **База даних:** MongoDB Atlas + Mongoose ODM
* **Автентифікація та безпека:** Passport.js, JWT (`access_token` + перевірка `tokenVersion` для миттєвої інвалідації сесій при зміні пароля або бані), Bcrypt (хешування паролів)
* **Архітектура та захист:** Кастомні декоратори (`@GetUser`, `@Roles`), Guards (`JwtAuthGuard`, `RolesGuard`), глобальна валідація DTO (`ValidationPipe` з `whitelist` та `forbidNonWhitelisted`), глобальний перехоплювач помилок БД (`MongooseExceptionFilter`), інтерцептор цензури (`ProfanityInterceptor`)
* **Інтеграції:** Cloudinary API (хмарне завантаження фото чеків та звітів ТО), Telegram Bot API (сповіщення про заявки та події)

### Frontend (`/frontend`)
* **Фреймворк:** Next.js (App Router, TypeScript, React)
* **Стилізація:** Tailwind CSS, підтримка світлої та темної теми (Dark Mode), адаптивна верстка (Mobile & Desktop)
* **Візуалізація даних:** Recharts (динаміка ваги, категорії витрат, прогрес робочих ваг у вправах)
* **Зовнішні API:** Open-Meteo API (погода в реальному часі для міст України), ExchangeRate API (актуальні курси 11 світових валют до гривні)
* **HTTP-клієнт:** Axios з автоматичним підключенням JWT через Interceptors та `js-cookie`

### Інфраструктура
* **Контейнеризація:** Docker & Docker Compose (ізольоване середовище з hot-reload для розробки та деплою)

## ✨ Основний функціонал та модулі

1. **📊 Дашборд та інформери (`/`)**
   * Віджет погоди з вибором міста .
   * Трьохслотовий мультивалютний інформер із пулом на **11 основних валют** (`UAH`, `USD`, `EUR`, `PLN`, `GBP`, `CHF`, `CZK`, `CAD`, `JPY`, `TRY`, `AUD`).
   * Жива стрічка останніх дій користувача з усіх модулів.

2. **💸 Фінанси (`/finance`)**
   * Перемикання між **Особистим** та **Спільним (Сімейним)** бюджетом.
   * Фільтрація за типом і категоріями, сортування, серверна пагінація.
   * Прикріплення фотографій чеків через **Cloudinary**.

3. **📋 Дошка завдань (`/tasks`)**
   * Інтерактивна **Kanban-дошка** на 3 колонки (`Нові`, `В процесі`, `Виконано`).
   * Підтримка особистих та родинних задач із закріпленням відповідального виконавця та дедлайнів.

4. **🏋️ Журнал тренувань (`/workouts`)**
   * Фіксація силових вправ, робочої ваги, кількості повторень і підходів.
   * Автоматична побудова графіка прогресії робочої ваги для кожної окремої вправи.

5. **🍏 Активність і Здоров'я (`/health`)**
   * Розрахунок базового метаболізму (**BMR**) та динамічної норми калорій за формулою Міффліна-Сан Жеора на основі зросту, віку, статі та цільової ваги.
   * Облік спожитих калорій, пройдених кроків (з перерахунком спаленої енергії) та трекер води (`+250 мл`).

6. **🛠️ Дім та Техніка (`/home-tech`)**
   * Сервісна книжка для автомобілів та домашнього обладнання (інвертори, системи фільтрації води тощо).
   * Контроль дат останнього й планового ТО, пробігу та завантаження фотографій актів/деталей.

7. **📈 Візуальна Аналітика (`/analytics`)**
   * Зведені KPI-картки (чистий баланс, поточна та цільова вага, % закритих задач, загальна кількість тренувань).
   * Графіки Recharts з миттєвим перерахунком фінансових показників у будь-яку з 11 валют.

8. **👨‍👩‍👧 Сімейний доступ та Профіль (`/profile`)**
   * Створення родини або приєднання за унікальним 8-значним інвайт-кодом (`XXXX-XXXX`).
   * Безпечна зміна імені та пароля (з автоматичним скиданням старих токенів через інкремент `tokenVersion`).

9. **🛡️ Адмін-панель — God Mode (`/admin`)**
   * Доступна для ролей `ADMIN`, `SUPER_ADMIN`, `MANAGER`.
   * Перегляд статистики платформи, зміна ролей користувачів на льоту, блокування/розблокування акаунтів та генератор ключів активації Premium.

## 📂 Архітектура проєкту

Проєкт побудований за принципами модульності та розділення відповідальності (Separation of Concerns):

```text
family-life-manager/
├── backend/
│   └── src/
│       ├── auth/               # JWT-стратегія, Guards, Login/Register DTO
│       ├── common/             # Декоратори (@GetUser, @Roles), Фільтри помилок, Guards, Інтерцептори
│       ├── cloudinary/         # Сервіс завантаження зображень у хмару
│       ├── families/           # Логіка сімейних груп та інвайт-кодів
│       ├── finance/            # Транзакції, пагінація, зведення балансу
│       ├── health/             # Калорії, кроки, вода, розрахунок BMR
│       ├── home-tech/          # Обслуговування авто та побутової техніки
│       ├── premium-requests/   # Заявки на Premium та інтеграція з Telegram
│       ├── tasks/              # Kanban-задачі (особисті та сімейні)
│       ├── users/              # Профіль, налаштування тіла, адмін-методи, сідування адміна
│       ├── workouts/           # Щоденник силових тренувань
│       └── main.ts             # Глобальні пайпи, CORS, префікс /api, запуск на порті 5001
├── frontend/
│   ├── app/                    # Маршрутизація Next.js App Router (сторінки)
│   ├── components/             # Декомпозовані UI-компоненти за модулями:
│   │   ├── admin/              # Таблиця юзерів та аналітика CRM
│   │   ├── dashboard/          # Шапка, сітка модулів, жива стрічка дій
│   │   ├── finance/            # Зведення, фільтри та список транзакцій
│   │   ├── health/             # Форма параметрів тіла та картки калорій/води
│   │   ├── home-tech/          # Картки обслуговування техніки та авто
│   │   ├── profile/            # Управління родиною та інвайт-кодами
│   │   ├── tasks/              # Kanban-дошка завдань
│   │   ├── workouts/           # Графік прогресії ваги та історія підходів
│   │   ├── ui/                 # Базові перевикористовувані елементи (Button, Input)
│   │   ├── CurrencyWidget.tsx  # Мультивалютний інформер (11 валют)
│   │   └── ThemeToggle.tsx     # Перемикач Dark/Light теми
│   └── config/
│       └── api.ts              # Налаштований інстанс Axios з JWT-інтерцептором
└── docker-compose.yml          # Оркестрація контейнерів (Frontend: 3001, Backend: 5001)


🚀 Швидкий запуск через Docker (Рекомендовано)
Переконайтеся, що на вашому комп'ютері запущено Docker Desktop.
Клонуйте репозиторій та перейдіть у папку проєкту:
Bash
git clone <URL_ВАШОГО_РЕПОЗИТОРІЮ>
cd family-life-manager
Запустіть збірку та старт контейнерів:
Bash
docker-compose up --build
Відкрийте застосунок у браузері:
🌐 Frontend (Веб-інтерфейс): http://localhost:3001
⚙️ Backend API: http://localhost:5001/api
(Для повної зупинки контейнерів використовуйте docker-compose down).
🔑 Тестові доступи (Суперадмін за замовчуванням)
Під час першого запуску бекенду (onModuleInit у UsersService) система автоматично перевіряє наявність адміністратора в базі даних і створює дефолтний акаунт:
Email: admin@gmail.com
Пароль: admin123
Роль: ADMIN (повний доступ до /admin панелі та всіх модулів системи)
Ви також можете зареєструвати нового звичайного користувача через сторінку /register і змінити йому роль або видати Premium через Адмін-панель.
💻 Локальний запуск без Docker (Альтернативний варіант)
Якщо ви хочете запустити сервіси окремо через термінал:
1. Запуск Backend:
Bash
cd backend
npm install
PORT=5001 npm run start:dev
2. Запуск Frontend:
Bash
cd frontend
npm install
NEXT_PUBLIC_API_URL=http://localhost:5001 npm run dev -- -p 3001
